## Implementation Summary

- Added `src/js/fx-display.js` as the CNY/VND display-rate adapter.
- The adapter applies a timeout, validates positive finite numeric rates, caches only the last valid rate with `updatedAt`, and marks cache older than 7 days as stale.
- `src/js/auth.js` now calls the adapter and updates `state.fxRateAuto` only when a live or cached valid rate is available.
- FX failures update only the display message and keep VND accounting usable.
