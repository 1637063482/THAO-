## Behavior verified

- Redemption persists the terminal deposit state before optionally queuing actual interest.
- Rollover creates a deterministic new deposit first, then links the immutable old record; retries reuse only an exact matching target.
- Stable `deposit-interest-<id>-<maturity>` markers make the legacy yearly-ledger write idempotent.
- Queue failure restores both local ledger and pending-update entries. Partial settlement remains visibly retryable.
- Principal is never accepted by the income bridge. Zero, missing and unconfirmed interest do not enter income.
- Terminal records cannot be edited; archival remains available. User confirmation explicitly says only actual interest becomes income.
