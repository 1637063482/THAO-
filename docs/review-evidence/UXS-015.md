## PWA and accessibility behavior verified

- Root and Vite-public manifest/service-worker copies are byte-identical and covered against drift.
- Manifest is Vietnamese, has stable `/` id/scope/start URL, references 192/512 PNGs and includes a maskable entry.
- The install icon contains no text, currency symbol, flag or bank brand; it uses the approved warm amber/teal visual direction.
- A new worker waits until the visible update action sends `skipWaiting`; `controllerchange` performs exactly one normal reload.
- Navigation requests fall back to the cached app shell offline. External/Firebase requests are not intercepted.
- Cache cleanup is limited to this app's prefix rather than deleting unrelated origin caches.
- Auth errors/timeouts, loading, normal toast and update toast expose alert/status live regions.
- Quick-add close and mobile navigation labels localize through vi/zh. Deposit and settlement dialogs trap Tab/Shift+Tab and close with Escape.
