## RED and implementation notes

The form/view tests were created before their modules during the recovered WIP phase; the exact initial missing-module console transcript was not retained, so this evidence does not invent it. Subsequent review-driven regressions were reproduced and fixed for invalid calendar dates, binding actions, true total principal, tablet action visibility, embedded-form locale, snapshot-safe draft retention and privacy masking.

- All persisted rates convert from user percent input to integer ppm.
- Principal and optional expected interest accept only non-negative safe-integer VND.
- Repository mutation status remains syncing/error until the listener confirms data; offline snapshots never claim synced.
- The form host is outside the live list root so a Firestore snapshot cannot discard a draft.
- Archive is soft archive through `DepositRepository.archive`; archived records remain visible under the archive filter.
