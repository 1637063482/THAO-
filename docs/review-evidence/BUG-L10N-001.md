## Bugs Fixed

### Bug 1: 语言切换后部分界面未更新（需手动刷新）

**Root cause**: `switchLanguage()` in `src/js/main.js` called `fullRebuildDOM()` (the original imported function from `render.js`) instead of `window.fullRebuildDOM()` (the overridden version). The `window.fullRebuildDOM` override at line 571 appends `initDashboard()`, `refreshSavingsView()`, and `refreshDepositView()` after the DOM rebuild — these are essential for updating the dashboard text, savings view labels, and deposit management labels to reflect the new locale. Without them, those sections kept the old language until a full page refresh.

Additionally, `updateCharts()` was never called after language switch, so the chart category labels (e.g., "Ăn uống" → "餐饮") remained in the old language.

**Fix**:
1. Changed `fullRebuildDOM()` → `window.fullRebuildDOM()` in `switchLanguage`
2. Added `updateCharts` import and call

**Files modified**:
- `src/js/main.js` (lines 9, 437, 439)

### Bug 2: 分析界面按钮无显示 + 主页年度月度分析消失

**Root cause**: `switchMobileView()` is called from `navigateTo()` in `navigation.js`, which is triggered by clicks on **both** the mobile bottom-nav items AND the desktop sidebar items. On desktop (>=768px), clicking a sidebar item such as "overview" would call `switchMobileView("overview")` which set `sidebar.style.display = "none"` — hiding the analysis panel (yearly/monthly charts and stats) that lives in the sidebar. 

This means:
- On desktop: clicking the sidebar "stats" item → hides the main column → analysis panel is shown but user sees an empty page
- On desktop: clicking "overview" sidebar item → hides the sidebar → analysis panel disappears

**Fix**: Added a viewport width guard at line 545: if `window.innerWidth >= 768`, the display toggle is skipped entirely. On desktop, sidebar items only update the active visual state via `setActive()` but never hide either column. Mobile behavior is unchanged.

**Files modified**:
- `src/js/main.js` (lines 543-545)
