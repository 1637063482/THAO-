## Implementation Notes

- `openQuickAdd()` marks the modal open, records the FAB trigger, populates the Vietnam-business-date selector, and focuses amount.
- Escape closes the sheet; Tab and Shift+Tab wrap within the sheet controls.
- `closeQuickAdd()` restores `aria-hidden`, hides the modal, and returns focus to the trigger.
- Mobile CSS uses a bottom-aligned full-width sheet, bounded scrolling, and `env(safe-area-inset-bottom)`; desktop remains a centered dialog.
- The existing legacy aggregate write path remains in place: keys stay `<month>_<day>_<category>`, income uses the existing `income` category, and duplicate same-day additions remain formula aggregation rather than transaction objects.
- Input clearing occurs only after `triggerCloudSave()` returns; a synchronous save failure leaves entered values visible for retry.
