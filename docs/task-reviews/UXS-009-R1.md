## Blocking findings

### High — Savings status is not connected to the actual sync lifecycle

- **Files:** `src/js/main.js:87-98`; `src/js/savings-view.js:26-27`.
- **Evidence:** Saving calls `triggerCloudSave()` and then immediately re-renders the savings view as `queued`. The existing queue's later `syncing`, `synced`, and `error` transitions call only `updateSyncStatus()` for the navigation indicator; none invokes `refreshSavingsView()`. Further, `renderSavingsPage()` maps every status other than `error` and `queued` to the `synced` label, so an explicit `syncing` status is rendered as synced.
- **Impact:** The required queued/syncing/synced/error states are not truthful or recoverable; a failed cloud write can remain displayed as queued.
- **Minimum correction:** Add a scoped state bridge from the actual queue lifecycle to the savings view, render all four statuses distinctly, and test success and failure transitions without reporting success before the write succeeds.

### High — Form validation failure destroys the user's input

- **File:** `src/js/savings-view.js:30-38`.
- **Evidence:** On an invalid monthly/annual value, the catch block calls `onStatus("error")`. In production that calls `refreshSavingsView("error")`, which replaces `#savings-root.innerHTML` using only persisted settings. The entered invalid/draft values are discarded.
- **Impact:** This directly violates the requirement that failure retain the input for recovery.
- **Minimum correction:** Keep drafts across validation and sync errors, then add an interaction test that submits an invalid value and verifies both input values and an understandable error state remain visible.

### High — Required responsive screenshot evidence is absent

- **Evidence:** No files under `docs/review-evidence/assets/` match `UXS-009`; the evidence document contains only a textual layout claim.
- **Impact:** The required 390/768/1440 screenshots, privacy-mask verification, long-Vietnamese layout check, and responsive no-overflow evidence are missing.
- **Minimum correction:** Generate and commit synthetic-state captures for 390, 768, and 1440 from the delivered revision, including the summary and form, privacy mask, Vietnamese/Chinese rendering, and no-page-overflow results; record the reproducible command and exit code.
