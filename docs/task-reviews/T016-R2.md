## Findings

### High

1. The R2 reconciliation occurs too late to prevent the rounded intermediate CNY conversion from being sent to Firestore, and it does not schedule the corrected VND value after blur.
   - Evidence: a CNY `input` still immediately writes the rounded conversion to state/pending and calls `triggerCloudSave()` at `src/js/main.js:61-88`. R2 restores `vndVal` to state/pending only during focusout at `src/js/main.js:103-133`, but does not call `triggerCloudSave()` there. The production queue flushes 800ms after the input event, copies and clears pending before `setDoc()` at `src/js/sync.js:32-55,86-103`; `triggerCloudSave()` is the only production scheduling entry point at `src/js/sync.js:108-110`.
   - Reproduction: begin with raw VND `1234` at rate `3500`; focus displays `0.35`; re-enter `0.35`. The input path produces `1225` and schedules a cloud flush. If the user remains in the field for more than 800ms, the queue sends and clears `1225`. On blur, R2 writes `1234` back to `state.appState` and `pendingUpdates`, but leaves it unscheduled, so the server can retain `1225` until an unrelated future save. The visible DOM displays `1234`, creating the same user-visible accounting discrepancy through a timing path.
   - Test gap: `tests/unit/currency-view.test.js:114-130` dispatches input and focusout synchronously while `sync.js` is mocked. It proves only final in-memory values; it neither advances the 800ms queue window nor proves that the interim value was not sent and the correction was scheduled.
   - Impact: an ostensibly no-op CNY round-trip can persist a rounded VND value, violating T016's VND-fact and no-drift completion criteria.
   - Minimum required change: use one authoritative CNY direct-cell persistence boundary. Prefer deferring CNY state/pending writes and cloud scheduling until focusout computes the final VND value, rather than queuing each CNY keystroke. Add a regression test that holds the CNY field longer than the 800ms debounce before blur and verifies no `1225` write can be emitted; then verify the only pending/sent VND value is `1234` for this no-op-equivalent sequence.

No Critical findings. No additional Medium or Low findings.
