## Findings

### High - Budget-heading test does not test the production renderer it claims to cover

- **Files/lines:** `tests/unit/budget-heading-i18n.test.js:20-23`; `src/js/render.js:91-105`.
- **Evidence:** The test defines its own `makeHeading()` function that concatenates `monthId` and `i18nModule.t("budget")`. It never imports/calls `renderMonthTable()`, sets no real table DOM, and asserts no `#budget-label-month` produced by the renderer. A production change that removes `t("budget")` (the exact R4 regression) can leave this test green.
- **Impact:** The plan-authorized “budget heading rendering and switch verification” is not actually implemented. The R4 UI regression can recur undetected.

### Medium - Evidence's canonical file inventory omits the R5 test file

- **File/lines:** `docs/review-evidence/UXS-002.md:35-62`.
- **Evidence:** The R4→R5 rework section mentions `tests/unit/budget-heading-i18n.test.js`, but the evidence's New Files and Modified Files inventories do not list it.
- **Impact:** The required modified-file/evidence handoff is incomplete for the reviewed head.
